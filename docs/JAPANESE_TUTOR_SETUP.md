## 5. 사용 흐름

1. 홈의 **일본어 튜터**를 엽니다.
2. 인사·자기소개, 카페, 식당, 쇼핑, 길 찾기, 호텔, 교통, 편의점, 오늘 하루, 여행 중 하나를 선택합니다.
3. Haru의 첫 질문을 일본어·한글 발음·한국어 뜻으로 봅니다. 가나 읽기는 펼쳐서 확인합니다.
4. 듣기 버튼으로 일본어 문장을 듣고 **말하기**를 누릅니다. 첫 사용 시 마이크 동의를 확인합니다.
5. 인식된 문장을 확인하거나 수정한 뒤 **인식된 문장을 확인했습니다**를 체크하고 전송합니다. 자동 전송하지 않습니다.
6. 막히면 **대답이 막힐 때**의 예시를 확인하고 **따라 말하기**로 연습합니다.
7. 일본어를 모르면 한국어로 직접 입력하거나 말하기 언어를 **한국어로 질문**으로 바꿀 수 있습니다.

표시 예:

> コーヒーを一つください。  
> 코오히이오 히토츠 쿠다사이.  
> 커피 하나 주세요.

학습 설정의 수준은 **처음 시작 / 기초 회화 / 일상 회화**입니다. 영어 수준과 별도로 저장되며 자동 승급하거나 JLPT 점수로 표시하지 않습니다.
영어·일본어 튜터에서는 앱 하단의 홈/즐겨찾기/설정 메뉴를 숨깁니다. 왼쪽 위 뒤로가기로 앱으로 돌아갑니다.
오른쪽 위 **더보기(…) → 학습 메뉴**에서 복습, 학습 설정, 이전 대화 선택, 새 주제, 대화 삭제를 이용합니다.
입력창 아래 **말하기 / 제출하기** 버튼을 나란히 표시합니다. 말하기 중에는 **말하기 종료**로 바뀌며, 음성 문장을 확인하기 전에는 제출할 수 없습니다.
이 집중형 UI 변경은 SQL이나 서버 함수의 추가 변경을 요구하지 않습니다. 아직 적용하지 않은 위 일본어 SQL/함수 배포는 그대로 필요합니다.
듣기 속도는 아주 천천히/천천히/보통 중 선택합니다. 속도는 현재 화면에서만 유지됩니다.
준비된 첫 질문·예시는 Hive 호출 없이 표시합니다. 답을 전송할 때부터 API 비용이 발생합니다.

## 모델과 음성의 한계

- 현재 연결 모델은 Hive의 `deepseek-ai/deepseek-v4.1-flash-1017`입니다. [Hive 공식 모델 문서](https://docs.thehive.ai/docs/deepseek-v41-flash)는 텍스트/이미지 입력과 텍스트 출력을 안내하지만, 일본어 회화·발음 표기 품질의 별도 보증이나 평가 결과는 제공하지 않습니다.
- 따라서 이 모델이 일본어에 강하거나 약하다고 단정하지 않았습니다. 실제 유료 모델로 일본어 교정·번역·읽기 품질 검수는 배포 후 필요합니다. 자동 테스트는 미리 준비한 가짜 답변으로 프로그램 동작을 확인합니다.
- 한글 발음은 근사치입니다. 일본어 장음·촉음·피치 악센트를 완벽히 표현하지 못합니다. 가능하면 일본어 음성도 함께 들으세요. AI가 한자의 읽기나 뜻을 틀릴 수 있습니다.
- 음성 인식/읽기는 Hive의 음성 모델이 아니라 브라우저·기기의 기능입니다. [SpeechRecognition 언어 설정](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/lang), [사용 가능한 음성 목록](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)을 사용합니다.
- 음성 인식은 브라우저 외부 서비스로 전송될 수 있습니다. 앱에는 원본 녹음이 아닌 확인된 텍스트만 저장됩니다. 기기의 TTS 엔진에 따라 음성 합성도 외부 서비스가 관여할 수 있습니다.
- 일본어 음성이 없는 기기는 안내를 표시합니다. 다른 언어 음성으로 임의 대체하지 않습니다. 음성 인식 미지원 기기에는 직접 입력이 남습니다.
- 텍스트만으로 발음·억양·유창성을 평가하거나 점수를 매기지 않습니다. 완전한 실시간 통화/발음 평가 기능은 아닙니다.

## 구현과 데이터 분리

- `JapaneseTutor.jsx`, `JapanesePhrase.jsx`, `JapaneseTutor.css`: 모바일 말하기 화면, 4종 표기, 복습, 사용량.
- `useJapaneseSpeech.js`: `ja-JP` 음성 인식·재생, `ko-KR` 질문, 마이크 동의, 해제 시 정지.
- `useEnglishTutor.js`의 공통 `useTutor`: 언어별 호출 함수·저장소 접두어를 주입. 영어 기존 키는 유지, 일본어 키에는 `goodlife-japanese-tutor`와 userId 포함.
- `useTutorAdmin.js`: 공통 권한 토글·사용량 조회. 영어/일본어는 독립된 상태로 관리.
- `japanese-tutor/core.mjs`: 일본어 회화 프롬프트, 문장/가나/한글/뜻 검증, 일본어 오류만 교정. 읽기 정답 여부를 기계적으로 보장하는 것은 아님.
- `japanese-tutor/topics.mjs`: 첫 질문과 예시 10종. 사용자 레벨은 서버에서 읽어 스냅샷 저장.
- `japanese-tutor/index.ts`: 공통 인증·저장·Hive 처리기에 일본어 교육 규칙을 주입. 서버가 테이블 접두어를 고정하며 브라우저는 테이블/모델/다른 사용자 ID를 지정할 수 없음.
- 서버 대화 문맥은 본인 일본어 세션에서만 읽음. 영어 기록·생활 기록·이메일·키는 프롬프트에 넣지 않음.
- `feedback.reply_reading`, `feedback.natural`은 `{sentence,reading_kana,pronunciation_ko,meaning_ko}`를 보관. 교정 제안에는 짧은 `explanation_ko`도 있음. 첫 질문/예시는 세션 `opening`에 저장.
- 공급자 `total_tokens`를 일본어 전용 날짜별 집계에 기록. 누락된 사용량은 미확인으로 남기며 가짜 예약량을 더하지 않음. 대화를 지워도 집계는 유지.
- RLS는 자기 데이터만 읽도록 유지. 관리자 전체 사용량 조회와 권한 변경은 서버와 DB에서 관리자 역할을 검사. 일일 제한이 없으므로 사용량에 비례해 비용 증가.

## 배포 후 직접 확인

- 본인과 배우자 계정에서 각자 대화/수준이 분리되는지 확인합니다.
- 일본어 질문마다 일본어·한글 발음·뜻이 나오고 듣기에서 일본어가 재생되는지 확인합니다.
- 안드로이드 Chrome에서 `コーヒーをください`를 말해 문장 확인 후 전송합니다. 조용한 환경에서도 기기/서비스에 따라 인식 결과가 달라질 수 있습니다.
- `커피 한 잔 주세요` 입력 시 일본어 표현 예시가 붙는지 확인합니다.
- 정확한 일본어를 불필요하게 교정하지 않는지, 불분명한 말을 임의로 번역하지 않는지 확인합니다.
- 실패 후 입력이 유지되고, 영어 대화/초안/토큰에 일본어 데이터가 섞이지 않는지 확인합니다.

## 아이폰 말하기 점검

- 마이크 연결 중에는 준비 안내와 **준비 취소**가 보입니다. 브라우저의 인식 시작 신호 이후에만 **말하기 종료**로 바뀝니다.
- **말하기 종료**를 누르면 최종 문장을 기다린 뒤 입력할 수 있습니다. 문장 확인 후 제출하는 기존 절차는 유지됩니다.
- 권한 거부, 언어 미지원, 마이크 사용 실패, 네트워크 오류, 음성 미감지를 각각 안내하고 괄호 안에 브라우저 오류 코드를 표시합니다. 원인을 제공하지 않은 경우 추측해서 단정하지 않습니다.
- 오류의 **다시 말하기**는 마이크만 다시 시작합니다. Hive 요청이나 학습 기록 재조회는 하지 않습니다.
- 시작 응답 12초, 인식 응답 60초, 종료 응답 4초 지연 시 해제합니다. 새로고침 없이 재시도할 수 있고 기존 입력 문장은 유지됩니다.
- 다른 앱으로 이동하거나 페이지를 닫으면 마이크를 해제합니다. 다시 말하기는 직접 눌러야 하며 자동 재시작하지 않습니다.
- iPhone Safari에서 일본어/한국어를 각각 말해 확인하고, 실패하면 오류 코드와 iOS 버전을 함께 확인합니다. 음성 인식은 기기·브라우저 서비스에 의존하므로 코드 수정만으로 모든 기기 지원을 보장할 수는 없습니다.
- 이번 마이크 수정에는 SQL 적용, Edge Function 재배포, 추가 API 키가 필요 없습니다. 웹앱 배포만 필요합니다.

개발 검증: `tests/japanese-speech.test.mjs`는 오류 안내를, `tests/japanese-speech.browser.mjs`는 실제 일본어 화면에 가짜 `webkitSpeechRecognition`을 넣어 지연·실패·재시도·화면 이탈을 검사합니다. 녹음/유료 API/실제 계정 데이터는 사용하지 않습니다.

## 한글·혼합 입력 표현 코칭 (2026-10-19)

- `커피 주세요`처럼 한글만 입력하거나 `コーヒーを 두 잔 주세요`처럼 섞어 입력하면, 완성된 일본어 문장에 **이럴 땐 이렇게 말해요** 설명을 붙입니다. 이미 맞게 쓴 일본어는 최대한 유지합니다.
- 처음 시작 단계는 핵심 표현 1개, 나머지 단계는 최대 2개를 설명합니다. 예: `두 잔` → `二杯` / `니하이`. 어떤 상황에 쓰는지 한국어로 설명하며 전체 추천 문장과 각 핵심 표현 모두 한글 발음을 제공합니다.
- `feedback.natural`의 기존 문장/가나/한글 발음/뜻/설명은 유지합니다. 새 `feedback.expression_tips`는 `{source,sentence,reading_kana,pronunciation_ko,meaning_ko,explanation_ko}` 배열입니다. 실제 한글 원문과 추천 문장에 존재하는 표현만 저장하고 필수 읽기가 빠지면 거부합니다.
